# LAN Messenger (PC1 <-> PC2)

Simple chat built with HTML, CSS and JavaScript. No database; messages live in memory only.

## Setup

1. Install Node.js (https://nodejs.org) on **PC1** (the computer that will host the chat).
2. Copy these files into one folder: `server.js`, `index.html`, `style.css`, `app.js`.
3. On PC1, open a terminal in that folder and run:

       node server.js

   It prints something like `http://192.168.1.10:3000` – that is PC1's IP address.
4. On **PC1** open `http://localhost:3000`.
5. On **PC2** open `http://<PC1-IP>:3000` (e.g. `http://192.168.1.10:3000`).
6. Enter a name on each PC and start chatting.

## If PC2 can't connect

- Both PCs must be on the same network (same Wi-Fi/router).
- Allow Node.js through the firewall on PC1 (Windows: allow "Node.js" on Private networks),
  or allow inbound TCP port 3000.
- Check PC1's IP with `ipconfig` (Windows) or `ifconfig` / `ip a` (Mac/Linux).
- To use another port: `PORT=4000 node server.js` (Windows CMD: `set PORT=4000 && node server.js`).

## Notes

- Restarting the server clears the chat history.
- Any extra device on the same network can join the same way.
